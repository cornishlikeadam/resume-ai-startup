# Metrics

Live job count means the number of distinct returned provider postings in the latest filtered batch. Every result retains source, source URL, retrieval time, and provider posting time when valid. Coverage is Europe-focused, capped to the latest provider batch, and is not exhaustive.

Unknown salary stays null. No invented salary, ATS acceptance, interview probability, response speed or conversion uplift is displayed.

Tracked jobs are records saved by the candidate. “User-reported applied”, “Interview”, “Offer” and “Closed” are self-reported labels. Opening a listing does not confirm submission. Email-sent stays false because this release sends no outreach.

[[Launch Status]] records which checks are complete.
